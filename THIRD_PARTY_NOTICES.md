# Dependency notices

OpenTiger uses independent Python packages installed through requirements.txt:

- [dnspython](https://www.dnspython.org/) for DNS record queries.
- [Pillow](https://python-pillow.org/) for image metadata, image copies, and documentation preview rendering.
- [phonenumbers](https://github.com/daviddrysdale/python-phonenumbers) for offline numbering-plan metadata.

Each package retains its own license and distribution notices. Consult the corresponding project or installed distribution for its complete license. These packages are dependencies; their source is not bundled into OpenTiger's application directory.
